좋은 알고리즘이란 실행에 걸리는 시간도 적고 자원의 사용량도 적은 효율적인 로직을 의미합니다.

## 알고리즘 평가 지표

- **시간 복잡도 (Time Complexity)**: 알고리즘이 얼마나 빠르게 실행되는가?
- **공간 복잡도 (Space Complexity)**: 알고리즘 실행에 얼마나 많은 메모리 자원이 필요한가?

시간과 공간은 대게 반비례 관계에 있지만, 현대 컴퓨터 과학에서는 시스템 성능 향상에 따라 주로 **시간 복잡도**를 위주로 효율성을 판단합니다.

## Big-O notation (큰-O 표기법)

알고리즘이 데이터량 $n$의 변화에 따라 어느 정도의 실행 속도 패턴을 보이는지 최악의 경우를 기준으로 나타내는 점근 표기법입니다.

- **$O(1)$**: 상수 시간. 입력 크기에 관계없이 일정한 시간이 걸림.
- **$O(n)$**: 선형 시간. 입력 크기에 비례하여 시간이 증가함.
- **$O(n^2)$**: 이차 시간. 입력 크기의 제곱에 비례하여 시간이 증가함 (예: 중첩 반복문).
