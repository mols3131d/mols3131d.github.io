## SQL (Standard Query Language)

- Query Language
- SQL은 특정 데이터에 [CRUD](https://ko.wikipedia.org/wiki/CRUD)작업이 필요할때 DBMS에게 요청을 보내는 방식에 대한 선언형 질의언어라고 생각하면 된다
- 명령형 VS 선언형 (Imperative Vs Declarative)

  | 명령형 | 목표가 어떻던 간에 어떻게 할 것인가? 에 집중 |
  | ------ | -------------------------------------------- |
  | 선언형 | 과정이 어떻던 간에 무엇을 할 것인가? 에 집중 |
