최적화 문제의 해를 찾기 위한 알고리즘 중 하나.

경사하강법은 함수의 기울기를 이용하여 함수의 최솟값을 찾는 알고리즘.

경사하강법의 이름은 기울기(slope)와 하강(descent).

함수의 기울기를 이용하여 함수의 최솟값을 찾기 때문.

## **설명**

경사하강법은 다음과 같은 과정을 통해 최솟값을 찾는다.

1. 초기점을 설정한다.
2. 초기점에서 기울기를 계산한다.
3. 기울기 방향으로 이동한다.
4. 2~3을 반복한다.

경사하강법은 다음과 같은 특징이 있다.

- **단순성** : 경사하강법은 알고리즘이 단순하기 때문에 구현하기 쉽다.
- **효율성** : 경사하강법은 데이터 포인트 하나씩을 사용하여 기울기를 계산하기 때문에, 데이터가 많을 경우에도 효율적으로 최솟값을 찾을 수 있다.
- **적용 범위** : 경사하강법은 다양한 최적화 문제에 적용할 수 있다.

## **특징**

경사하강법은 다음과 같은 특징을 가진다.

- **단순성** : 경사하강법은 알고리즘이 단순하기 때문에 구현하기 쉬운 **장점**이다.
- **효율성** : 경사하강법은 데이터 포인트 하나씩을 사용하여 기울기를 계산하기 때문에, 데이터가 많을 경우에도 효율적으로 최솟값을 찾을 수 있는 **장점**이다.
- **적용 범위** : 경사하강법은 다양한 최적화 문제에 적용할 수 있는 **장점**이다.

## **확률적 경사하강법**

매번 데이터 포인트 하나씩을 사용하여 기울기를 계산하는 방법이다. 확률적 경사하강법은 데이터 포인트 하나씩을 사용하여 기울기를 계산하기 때문에, 데이터가 많을 경우 계산 시간이 오래 걸릴 수 있다.

- 랜덤하게 데이터 하나씩 뽑아서

## **뉴턴-라프슨 경사하강법**

함수의 2차 도함수를 사용하여 기울기를 계산하는 방법이다. 뉴턴-라프슨 경사하강법은 확률적 경사하강법보다 빠르게 최솟값을 찾을 수 있지만, 함수가 2차 도함수가 존재하는 경우에만 사용할 수 있다.
