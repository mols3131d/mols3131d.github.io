# 베이즈 룰 (Bayes' Rule)

베이즈 정리는 새로운 정보(증거)가 주어졌을 때 기존의 가설에 대한 확률을 어떻게 업데이트해야 하는지 보여주는 강력한 도구입니다.

$$P(H|E) = \frac{P(E|H)P(H)}{P(E)}$$
