# 결측치(Missing Data)란?
데이터 집합에서 일부 데이터가 누락되어 비어 있는 상태를 의미합니다. (Missing values, 손실 자료)

결측치는 분석 결과의 편향을 초래하거나 머신러닝 모델의 오류를 발생시킬 수 있으므로, 삭제 또는 대치(Imputation) 등의 적절한 전략이 필요합니다.
